# Feature matrix — Keyframe Labs versus EmoStream targets

Labels and evidence IDs are defined in [evidence_and_limitations.md](evidence_and_limitations.md). The EmoStream column states *targets*, not results.

| Feature | Keyframe Labs (what the evidence says) | Label | EmoStream target |
|---|---|---|---|
| Input identity | Stock avatars selected by `persona_id` / `persona_slug`; custom image-to-avatar on Enterprise | DOC (E6, E7) | Any single consented portrait, uploaded by the user, no per-identity training |
| Audio input | 24 kHz, 16-bit PCM, mono, pushed in chunks with `sendAudio` | STATIC (E4) | Microphone or uploaded file, resampled to 16 kHz for the model |
| Audio source | Agent/TTS audio from the customer's stack; any stack via the SDK | DOC (E6) | The user's own voice (live mic) or an uploaded recording |
| Conditioning on raw audio | "rather than on a transcript or phonemes" | DOC (E5) | Same: self-supervised speech features from raw audio |
| Lip sync | Claimed "accurate lip sync" | DOC (E2) | SyncNet LSE-C within 5% of best local baseline |
| Head motion, gaze, blinks | Generated by the behaviour model; idle motion when audio is absent | DOC (E5) | Blinks, brows, gaze, nods/tilts generated from audio + emotion |
| Emotion set | Docs: neutral, happy, sad, angry. SDK 0.3.0: neutral, happy, sad, angry, surprised, concerned, confused, disgusted, excited, scared, skeptical | DOC (E6), STATIC (E4) | neutral, happy, sad, angry, surprised |
| Emotion control | Discrete label, changeable mid-conversation, set manually or by an agent tool call | DOC (E6), STATIC (E4) | Discrete label selected in the UI, changeable during a stream |
| Emotion timing | Cue attached to a sample offset in the audio stream; applied on the 40 ms video frame containing that sample | STATIC (E4) | Emotion change takes effect at a chunk boundary with a smooth transition |
| Emotion intensity | No public intensity parameter. The article describes an internal per-signal guidance scale tuned before release | DOC (E5), E6 "not found" | User-controlled intensity 0–1 |
| Frame rate | 25 FPS (one frame per 40 ms) | DOC (E5), STATIC (E4 comment) | 25 FPS target, 15 FPS gate |
| Resolution | Not specified; "effective facial resolution of 720-1080p" | DOC (E6) | 256×256 minimum, 512×512 if speed allows |
| Latency | ~180 ms audio-in to video-out; ~500 ms typical turn; docs say ~500 ms rendering latency | DOC (E5, E6) | p50 ≤ 350 ms, p95 ≤ 500 ms audio-to-frame |
| Transport | LiveKit room: video and audio as WebRTC tracks, audio upload as a LiveKit byte stream, control over data messages | STATIC (E4) | WebSocket first (binary audio up, encoded frames down); WebRTC as a later upgrade |
| A/V synchronisation | Avatar publishes its own audio track alongside video, so playback is synchronised server-side | STATIC (E4) | Server returns frames with sample-accurate timestamps; client plays the audio it captured against them |
| Interruption | `interrupt()` clears the worker's pending frame queue | STATIC (E4) | Stop button flushes queued audio and frames |
| Session length | "Unlimited call length" (plan limits 5–60 min below Enterprise) | DOC (E2, E7) | Five-minute stability test |
| Concurrency | "1000s of concurrent sessions", multi-region | DOC (E2) | Single session on one GPU |
| Data retention | "Zero data retention mode" | DOC (E2) | No raw uploads stored by default |
| Model size | persona-1.5-live: "200M parameter model" | DOC (E2, E7) | Small trainable behaviour model (order of 1–20 M parameters) + frozen pretrained renderer |
| Renderer | Diffusion renderer, few-step distilled, per-frame, no history | DOC (E5) | Pretrained warping-based renderer (LivePortrait family), frozen |
| Deployment hardware | Not stated; "one GPU serving many conversations" | DOC (E5) | Modal cloud GPU for the service; RTX 4050 6 GB as the reference budget |
| Listening behaviour | Not modelled ("only one side of the call"); named as future work | DOC (E5) | Out of scope (stretch goal in the FYP report) |
| Watermark / AI disclosure | Not observed | UNK | Visible AI-generated watermark, consent gate |
